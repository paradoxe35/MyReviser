# Encre FFI Library

Rust FFI library providing system input functionality (hotkeys, clipboard, keyboard simulation) for the Encre Go application.

## Features

- **Clipboard Management**: Cross-platform clipboard operations with save/restore
- **Key Simulation**: Simulate keyboard shortcuts (Ctrl+C, Ctrl+V, Ctrl+A, etc.)
- **Global Hotkeys**: Register and listen for system-wide hotkey events

## Building

### Requirements

- Rust 1.70+ with cargo
- C compiler (gcc, clang, or MSVC)
- Platform-specific dependencies:
  - **Linux**: X11 development libraries, musl-tools for static builds
  - **macOS**: Xcode Command Line Tools
  - **Windows**: MinGW-w64 for static builds

### Build Commands

```bash
# Build static library for current platform
cargo build --release

# Build for Linux (static with musl)
rustup target add x86_64-unknown-linux-musl
RUSTFLAGS="-C target-feature=+crt-static" \
    cargo build --release --target x86_64-unknown-linux-musl

# Build for Windows (static with MinGW)
rustup target add x86_64-pc-windows-gnu
RUSTFLAGS="-C target-feature=+crt-static" \
    cargo build --release --target x86_64-pc-windows-gnu

# Build for macOS
cargo build --release --target x86_64-apple-darwin
```

### Output

- Static library: `target/release/libencre_ffi.a`
- C header: `bindings.h` (auto-generated by cbindgen)

## Usage from Go

See the Go CGO wrappers in `../internal/input/ffi_*.go` for usage examples.

### Example

```go
import "C"

// Create clipboard manager
clipboard := C.encre_clipboard_new()
defer C.encre_clipboard_free(clipboard)

// Set text
text := C.CString("Hello from Rust!")
defer C.free(unsafe.Pointer(text))
C.encre_clipboard_set_text(clipboard, text)
```

## API Reference

### Clipboard Functions

- `encre_clipboard_new()` - Create clipboard manager
- `encre_clipboard_get_text(handle)` - Get clipboard text
- `encre_clipboard_set_text(handle, text)` - Set clipboard text
- `encre_clipboard_save(handle)` - Save current clipboard
- `encre_clipboard_restore(handle)` - Restore saved clipboard
- `encre_clipboard_free(handle)` - Free clipboard manager

### Key Simulator Functions

- `encre_simulator_new()` - Create key simulator
- `encre_simulate_select_all(handle)` - Simulate Ctrl+A/Cmd+A
- `encre_simulate_copy(handle)` - Simulate Ctrl+C/Cmd+C
- `encre_simulate_paste(handle)` - Simulate Ctrl+V/Cmd+V
- `encre_simulator_free(handle)` - Free key simulator

### Hotkey Functions

- `encre_hotkey_manager_new()` - Create hotkey manager
- `encre_hotkey_register(handle, binding, action, callback)` - Register hotkey
- `encre_hotkey_start(handle)` - Start listening
- `encre_hotkey_stop(handle)` - Stop listening
- `encre_hotkey_manager_free(handle)` - Free hotkey manager

### Error Handling

- `encre_get_last_error()` - Get last error message
- `encre_free_string(str)` - Free string returned by Rust

## Error Codes

- `0` - Success
- `-1` - Null pointer
- `-2` - Initialization failed
- `-3` - Invalid argument
- `-4` - Operation failed
- `-5` - Invalid UTF-8
- `-6` - Not initialized
